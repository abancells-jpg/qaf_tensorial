# qaf_tensorial
Implementación de QAF mediante redes tensoriales

## Estructura del Repositorio

- : Manuscrito LaTeX completo del llibre (27 páginas) y pdf compilado
- : Redes tensoriales MPS, MPO, 1TDVP, 2TDVP
- : Extraccion 1-RDM / 2-RDM y fase z_ab
- : Reordenamiento RCM y compilador QUBO bandejado
- : QAFRouter metacognitivo para coordinacion multiagente
- : Scripts de validacion reproducible
- : Pruebas unitarias y oraculos exactos (K=8)
- : Jupyter Notebooks demostrativos

## Resultados Destacados

- **Precision CSRA:** 96.96% (QAF) vs 27.26% (Modelos clasicos)
- **Ahorro de Tokens:** Reduccion del 62.8% en consumo total
- **Reduccion de Trafico:** -69.87% en mensajes multiagente
- **Escalabilidad 50M:** 1.07 segundos (45.5M vars/s)
- **Fidelidad Exacta (K=8):** 1.000000 frente al oraculo de Schrodinger
